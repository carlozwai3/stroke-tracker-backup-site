Stroke Tracker Backup

Stroke Tracker Backup is a private, owner-operated utility intended to create encrypted backup copies of the Stroke Performance Tracker application's database and store them in a designated Google Drive folder.

The utility is not offered as a public sign-up service. Google authorization is intended only for the account owner to access files explicitly authorized for backup storage and backup status records.

Production database backups can include account and training records. Backup archives are encrypted before upload. This informational website does not display or provide access to those records.
